### 10-2. 技術選定の理由

- なぜこの技術を使うのか
- Rails：カリキュラムで学んだ知識を最大限活かし、開発スピードを重視するため
- PostgreSQL：本番環境との一貫性を保つ

- 今回チャレンジしたい点
- Renderへのデプロイと環境構築

- 不安な点
- Renderを始めて使用するため、エラーログを読み解き、適切に対処できるか
- ローカル環境と本番環境の違いを理解しきれていない
- Renderの公式ドキュメントを読んでイメージできるか
- 

- 対策
- エラーが出たら、ログを保存して技術面談で相談する
- Render公式ドキュメントを読み、手順をチェックリストにする

- 間に合えば挑戦する実装
- kaminari（ページネーション）メモが増えてきたら
- ransack（検索機能）


### 10-3.キャッチアップ不足の懸念
プログラミング初学者のため、エラーログを読むのに時間がかかり、原因の特定に時間がかかることが多い。
実務では納期があるため、エラーが出た時に短時間で解決できるか不安。
また、理解が不足している部分が多いので、カリキュラムで学んだ技術、知識を身につけ、基礎を固めていきたい。
